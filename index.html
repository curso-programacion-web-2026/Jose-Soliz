Sección 2: JavaScript Moderno

JavaScript es un lenguaje de programación robusto que se puede aplicar a un documento HTML.

Permite crear interactividad dinámica en sitios web como mapas interactivos, animaciones 2D/3D y mucho más.

CSS es el lenguaje que usamos para estilizar un documento HTML y definir su presentación visual.

Con CSS podés controlar el color, la tipografía, los espacios, las elecciones de diseño y las animaciones de tu página.
